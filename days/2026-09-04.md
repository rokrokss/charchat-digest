Nomi가 28시간 새 50커밋·PR 15개 안팎을 머지했다. 에이전트 '상주(resident)' UI v3.1 정상 상태 적용과 P0 예외 상태 카드(복구 이벤트 리스너 포함), 호스트 경계에서 에이전트 작업 모드 강제, MCP client\_elicitation 영수증 경로 연결과 E2E 저니, MCP 툴 설명 슬림화가 주요 기능. 캔버스는 모델 전환 후 되돌리기가 안 되던 textarea 포커스 버그, Runway Veo 3.1 선택 시 생성 패널이 죽던 stale 스냅샷 버그를 고쳤고, 연결선으로 모드가 좁혀질 때 안내 문구를 띄우되 끌 수 있게 했다. 외부(Codex) 리뷰가 '50/50 졸업' 주장을 뒤집은 감사 문서도 커밋됐다. ArtCraft는 웹앱 인증 페이지 영상 교체 커밋 1건뿐.

> 💡 캔버스에서 노드 연결이 선택 가능한 모드를 좁힐 때 이유와 대안을 인라인으로 설명하되 끌 수 있게 하는 패턴은 우리 캔버스에도 그대로 적용 가능.
