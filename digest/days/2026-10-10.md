### 🟡 Nomi 텍스트 노드 개편 — Agent 읽기·쓰기, 가공 메뉴·하류 '인용' 표시
**영상 제작** · Nomi · GitHub

Nomi가 캔버스 텍스트 노드를 손봤다(#1137). Agent가 텍스트 노드 본문을 읽고 쓸 수 있게 됐고, 노드 아래 가공 박스에서 프롬프트로 확장·이미지 보고 묘사·번역·여러 개로 분할·이어쓰기/고쳐쓰기를 'Agent 모델 따르기'로 실행하며, 텍스트가 연결된 하류 노드 입력창엔 '인용·텍스트명' 태그가 붙어 마우스를 올리면 내용을 보여준다. 연결 핸들도 쓸 수 있는 쪽에만 표시하고 좌우 메뉴·빈 노드 '해보기'를 Claude Design 시안대로 다시 만들었다(#1133).

> 💡 프롬프트 텍스트를 1급 노드로 두고 하류 연결을 '인용'으로 보여주는 방식은 캐릭터 설정·로어를 여러 생성 노드에 재사용하는 캔버스 설계에 바로 참고할 만하다.

### 🟡 Nomi 영상 노드 프레임 캡처·앱 내 업데이트 알림 — '노드 먼저 배치' 원칙
**영상 제작** · Nomi · GitHub

Nomi가 영상 노드 플로팅 바에 현재·첫·끝 프레임 캡처를 넣어 원본 옆에 이미지 카드를 만들고 연결선까지 잇게 했고(한 번의 Ctrl+Z로 취소, #1152), 로컬 처리 실패 카드에선 '모델 바꾸기'를 빼고 '재시도'만 남겼다. 상단 바 캡슐·업데이트 이유 팝업·핫픽스 배너·업데이트 완료 카드로 이뤄진 앱 내 업데이트 알림(#1135), 생성 요청 전에 캔버스에 노드부터 놓는 '먼저 배치, 나중 요청' 구조와 '남은 N장 생성'을 한 장씩 접수 확인 후 진행하는 변경(#1139)도 들어갔다. 새 릴리스는 없고 최신은 v0.23.1(10/8)이다.

> 💡 비싼 생성 요청 전에 결과물 자리부터 캔버스에 확정하는 원칙은 과금 분쟁과 결과 유실을 줄이는 패턴이라 Black Sabayon 영상 캔버스에도 적용할 만하다.
