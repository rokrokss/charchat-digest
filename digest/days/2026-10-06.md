### 🟡 Nomi 대형 프로젝트 성능 개선 — 다중 선택 합성 레이어 1137→57, 열기 시 쓰기 제거
**영상 제작** · Nomi · GitHub

Nomi가 전체 선택 후 드래그할 때 카드마다 붙던 크기 조절 핸들을 없애 합성 레이어를 1137개에서 57개로 줄였고, 드래그 중 노드 카드가 다시 렌더링되지 않고 위치만 바뀌도록 React Flow 성능 가이드대로 메모이즈했다. 프로젝트를 열 때 디스크에 쓰지 않게 하고 로컬 에이전트 런타임을 필요할 때만 불러오며, 로딩 중인 이미지에만 반짝임 자리표시를 줘 큰 프로젝트의 첫 이미지가 약 0.4초 빨라졌다. 에이전트는 스토리보드 화면비를 모델별 실제 파라미터 키로 넣고, 초안 수정 시 지목한 파라미터만 바꾸며, 모델이 지원하지 않는 길이는 초안 단계에서 합법값과 함께 거절하고, 답변 언어를 UI 언어에 맞추게 됐다.
