## 이번 주 동향

### \[2026년 10월 2주차 동향\] 제타 청소년 제한으로 연 주, 케이브덕 Alice 논란·Argon 대기

10월 2주차는 스캐터랩이 국회의원실의 세이프 모드 우회 점검 보도와 국정감사 증인 채택 직후 제타 청소년 이용을 하루 3시간·월 10만 원으로 묶겠다고 발표하며 열렸고, 크랙에 이어 양대 플랫폼이 모두 청소년 한도를 걸게 됐다. 유저 정서의 중심은 케이브덕으로, 월요일 'Keep thinking minimal' 노출로 추론 제한 불신이 번진 데 이어 화요일엔 (주)네오알리가 만든 신모델 'Alice' 공지가 앱에서 사라지고 개인정보 수탁 업체에 네오알리가 '연구 개발' 업무로 추가돼 데이터 활용 의심까지 얹혔으며, 신작란 이식 도배로 '테라포밍' 우려도 커졌다. 모델 쪽에선 Gemini 3.7 Flash 퇴출이 버블챗·루나톡에 이어 바베의 Gemini 2.5 Pro 종료(10/20)로 번지는 가운데 'Gemini 4 Argon'이 곧 풀린다는 기대가 채널을 달궜다. 공급 쪽에선 파베 종료 여파로 에덴·바베 장수작 '로얄 아카' 제작자가 에셋 제작 난항을 이유로 제작 중단을 밝혀 상실감이 컸고, 리루(인센티브·출석 크레딧 개편)·우마이(움니버스 공모전)·티키타(3개국 공모전)는 제작자와 유저를 끌어오는 판촉을 이어 갔다. 네코챗은 답변마다 장면 이미지를 그리는 'Churu Gen'을 예고해 멀티모달 RP의 방향을 보여 줬고, 영상 도구에선 ArtCraft가 스타 2.28만 개를 넘겼으며 Nomi는 캔버스 위 Agent 부분 수정 방안을 문서로 내놨다.
